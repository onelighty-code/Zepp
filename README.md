# Fenix Style EN — Amazfit Cheetah 2 Ultra

Native Zepp OS watchface project (English edition).

## Target
- Device: Amazfit Cheetah 2 Ultra
- Display: 480 × 480 (to be confirmed against the exact Zepp device target)
- Design: Garmin Fenix-inspired analog + digital layout
- Planned live data: steps, heart rate, calories, distance, battery
- Planned low-power AOD: separate simplified layout

## Build status
Project scaffold and device target are not yet validated. Do not install this repository as a watchface.

## Build tooling
The official Zepp OS documentation describes Zeus CLI:
- `zeus create` — create a Zepp OS project
- `zeus build` — build a `.zab` package
- `zeus preview` — compile and create a QR preview for installation through Zepp App Developer Mode

See https://docs.zepp.com/docs/guides/tools/cli/
